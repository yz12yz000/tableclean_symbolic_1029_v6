## 这两个命令分别做什么

```bash
./run_clear_table.sh             # 观察、定位和路径规划，不动机械臂/夹爪
./run_clear_table.sh --execute   # 请求真实逐碗抓放；当前会被运动许可拦截
```

观察到的碗盘才进入原有定位和抓放链路。杯子、勺子作为其他物体的占用圆盘参与空位避让；托盘分割深度也排除这些物体的掩膜。它们不进入碗的抓取点云，不会自动被抓取。

对已观察到的托盘内占用保留记录，即使下帧暂时漏检，也不把位置当空位。占用物体深度不可靠时停止/有限重观察。放置验证要求目标碗实际出现；杯子或勺子不能代替碗完成验证。

盘子归入bowl只改变任务分类，不保证其边缘、深度与夹持方式满足碗的原有抓取几何。当前模型也仍可能漏检或分割粘连，不能把识别类别齐全当作可以执行。
