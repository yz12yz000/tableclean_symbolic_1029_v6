# 杯口尺寸范围与恢复

2026-10-22按用户授权将现场碗/杯口圆拟合下限由半径4 cm扩展为3 cm（直径下限8 cm改为6 cm）。最大半径仍为15 cm。

限制仍有必要：圆拟合可能从噪声或局部曲线得到小圆，完全取消范围会增加错误定位。此次仅扩展到3 cm，没有改变残差、覆盖角度、内点比例、壁面支持、碰撞与轨迹检查，也没有执行机械臂运动。

## 当前设置

- `src/rim_locator/config/place_config.json`：`circle_min_radius=0.03`、`circle_max_radius=0.15`，控制抓取候选定位。
- `src/yolo_vision/config/clear_table_live.json`：`visual_rim_min_radius=0.03`、`visual_rim_max_radius=0.15`，控制占用中心和尺寸估计。
- 同文件`bowl_radius=0.03`是可接受占用半径下限，同步降低以避免有效小杯在后续验证又被旧4 cm下限拒绝。实际放置仍使用观测到的半径、测量不确定度和原有25 mm放置余量。

两处圆半径范围需同步修改，避免视觉中心有效而抓取候选无效。杯口半径不是物体外侧占用半径，也不是夹爪开口宽度；尺寸符合范围不保证可抓取。

## 现场观测

修改前采集的当前绿色杯子，在原4 cm下限下已拟合成功：半径约4.14 cm，残差约2.14 mm、覆盖角约233°，可生成4个抓取候选。因此此前失败不一定完全来自4 cm限制，也可能涉及不同帧、不同杯子或深度支持变化。

新范围支持约3.3 cm半径的合成杯沿，同时仍拒绝过小或只有短弧的观测。实机是否可执行，以修改后完整在线预览结果为准。

```bash
cd /home/rob/table_clean_ws
python3 - <<'PY'
import json
from pathlib import Path
p=Path('src/rim_locator/config/place_config.json')
c=json.loads(p.read_text())
c.update(circle_min_radius=0.04,circle_max_radius=0.15)
p.write_text(json.dumps(c,indent=2)+'\n')
p=Path('src/yolo_vision/config/clear_table_live.json')
c=json.loads(p.read_text())
c.update(visual_rim_min_radius=0.04,visual_rim_max_radius=0.15,bowl_radius=0.04)
p.write_text(json.dumps(c,indent=2)+'\n')
PY
```
