# 圆碗径向抓取：最小修改及验证

> 当前参数核对：`place_config.json` 为内点比例 0.4、接触误差 0.002 m、覆盖至少 120°，允许局部壁面备用分支。下文按时间记录的测试结果属于当时版本。

## 目标与动作

同规格、水平放置的圆碗；固定夹持高度/深度且夹起后无滑动。在这些前提下，让同一物理手指始终在碗外，另一根在内，降低抓取方向变化导致的放置偏移。不能仅凭软件保证每次碗中心完全重合。

流程继续为：新观察 → 碗沿抓取 → 抬升 → 移动并调整到示教准备姿态 → 按各点下降距离释放 → 上退 → 返回固定起点。五个放置点、起点、夹爪时序和机器人速度本次不改。蓝框中的准确放置目标仍需用一致夹法带碗示教。

## 实际修改

- `src/rim_locator/rim_locator/circle_fit.py`：只使用现有碗沿高度带的实际点，空间去重后做确定性稳健 XY 圆拟合；拒绝短弧、离群点过多、残差或半径越界，禁止退回点云中位数方向。
- `rim_detection.py`：原有局部碗壁支撑、双尺度一致性和候选搜索仍生效；用拟合圆心确定朝外符号，再以圆心到抓取点的水平径向生成工具 Y 轴。工具 Z 保持向下。
- 圆心径向分支的候选 XYZ 不向虚构圆周投影：当前配置只接受距拟合圆周 ≤2 mm 的实际候选点；墙面水平方向与圆心径向偏差 >20° 的候选拒绝。覆盖不足时的局部碗壁备用分支见下节。
- `config.py` / `place_config.json`：新增 `circle_radial` 模式及质量门槛、`outside_finger_axis`。通用旧配置的原模式继续可用；单碗放置入口启用新模式。
- `/rim_locator/grasp_candidates` 的版本、字段结构和工具坐标系不变。圆心、半径、残差、可见弧长、内外指向进入已有 `geometry` 诊断字段。
- `tools/place_rounds.py`：新几何拒绝原因允许运动前有限次数重新观察；一旦开始运动，不自动换候选重抓。
- `tools/debug_circle_grasp.py`：离线回放点云并输出 JSON 和 XY 几何图，无 ROS、机械臂或夹爪控制。

## 圆拟合质量门槛

半径 40～150 mm；内点距离门槛 4 mm，当前抓放配置的内点占比 ≥40%（历史门槛为 65%、50%），RMS 径向残差 ≤2.5 mm；当前可见弧长至少 **120°**，并覆盖至少 4 个 30° 角度区间。设置更高的弧长门槛时，所需区间数随之增加。半径范围是候选有效性范围，不是已测量的碗半径。

相机不必看到半圈碗沿。当前圆心径向分支要求至少 120°；低于该值或角度区间不足时，单碗配置启用局部碗壁备用方法，不使用被拒绝的短弧圆心来决定方向。残差、半径等其他圆拟合质量失败仍拒绝。此调整提高候选生成可用性，不保证实际抓取率或放置精度。

## 20:07 覆盖不足：增加局部碗壁备用方法（当前版本）

用户任务 `299f12a23c1b40bc99008edd9944c22a` 的三轮原始点云均未保存，不能声称还原了这三轮的具体覆盖角度。只读重新采集当前场景后复现同类失败：6682 个点，主连通分量 6681 个点，现有高度带筛出 512 个碗沿点，拟合内点占比 96.1%，覆盖角度约 101.0°。这说明在新采集帧中，主要限制来自高度带形成的局部弧段，圆拟合仅排除少量点；不能据此断言相机完全未看到碗，也不能证明被高度带排除的所有点都是有效碗沿。

当前方法：

1. 圆弧质量充分时继续使用原来的圆心径向方法。
2. 仅遇到 `circle_insufficient_coverage` 或 `circle_insufficient_sectors`，且 `circle_allow_wall_fallback=true` 时，尝试现有 `_supported_walls` 搜索。完整观测点云的中位位置仅用于区分碗壁法线的内外符号，夹持方向来自实际局部碗壁拟合；不使用被拒绝的短弧圆心。
3. 保留观测接触 XYZ、至少两个尺度的碗壁支持及法线一致性、竖直下降和固定物理手指约定。工具 +Y 仍对应左外指，−Y 对应右内指。纯碗沿而无壁面深度支持仍不能产生抓取候选。
4. 备用分支输出 `method: supported_wall_fallback`、触发原因、被拒绝圆拟合的实际覆盖角度、内点比例、筛选点数和高度范围。被拒绝的圆心仅保存在嵌套诊断中，不作为可信圆心发布。
5. 修复失败轮次点云落盘时序：即使候选消息已到达，也短暂等待调试点云，避免不同 ROS 话题到达顺序导致提前退出；未收到时记录 `base_cloud_delivery_timeout`。已有失败文件无法补回。

备用方向由局部壁面估计，因此固定释放位姿下的碗中心重复精度可能低于可靠完整圆拟合；不能承诺每次看到物体就一定抓住或每次落点完全相同。当前优化针对“有局部可靠接触证据，却因圆弧覆盖不足整轮拒绝”的问题，碰撞、不可达、缺失壁面证据等检查继续生效。
